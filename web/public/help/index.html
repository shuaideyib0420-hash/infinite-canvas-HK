Velumo 画布使用帮助

从本站入口打开画布，在设置的渠道页填写自己的 Velumo API Key，查询并选择有权限的模型，再创建画布或导入作品。可按模型选择 OpenAI 兼容或 Gemini 原生协议。

Key 默认仅本次页面会话使用；勾选“记住”才保存在此浏览器。作品、素材和历史主要保存在当前浏览器，请定期导出；配置导出排除 Key 和 WebDAV 密码。跨设备可用导入导出或自己的 WebDAV。

Windows 本地 Agent

  1. 安装 Node.js 官方受支持的 LTS 版本（包含 npm/npx）。
  2. 下载 本站启动脚本，在 PowerShell 运行。脚本会要求输入自己的本站 Key 和可用的文本模型 ID，不使用开发者凭据。
  3. 保留终端运行，在网页 Agent 面板填入终端显示的 Local URL 和 Connect token。每台电脑连接自己的本机服务。
  4. 在侧栏对话创建或修改节点；画布修改按官方流程确认。关闭终端后服务退出，再运行脚本即可重新连接。

若 Windows 阻止下载脚本运行，可在检查脚本内容后仅对本次进程执行：

powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\start-agent.ps1"

启动脚本使用独立的本站 Codex 配置目录，Key 只传给本次进程；不覆盖已有 Codex 登录或全局 MCP。网页模型 Key、Agent Connect token、本地 Codex 模型配置是三个不同对象。浏览器询问本地网络许可时，允许本站访问自己的 Agent。

插件、脚本与同步

画布插件管理提供官方 Markdown、SVG、HTML、3D 全景、便利贴节点。也可安装自己信任的插件；渠道模型的“调用脚本”可使用官方模板适配请求。第三方代码按官方方式在页面运行，请只使用自己信任的代码。

设置内保留本地代理、WebDAV、自定义提示词源、主题与语言。代理在自己的电脑运行；WebDAV由用户自行提供。手机和平板可用基础画布，本次本地 Agent 方式不提供免安装的云端 Agent。

用量与问题处理

Key 名称、分组及参考价可在渠道页手动查询；最终费用以本站控制台用量为准。超时、取消或断线可能已计费，请先核对用量再决定是否重试。图片已生成而保存失败时，重新保存已有结果，无需重新生成。

Windows为首发验收目标；macOS/Linux功能保留，实机验证状态另列。模型可用参数和权限以本站实际配置与验收清单为准。
